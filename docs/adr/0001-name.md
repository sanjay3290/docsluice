# 0001. Name: docsluice

- Status: Accepted
- Date: 2026-10-09
- Requirement IDs: PRD Q2

## Context

The PRD used the working name `docsift`. On 2026-10-09 the GitHub user/org `docsift` was taken, and a Python project named `docsift` does a similar job ("convert documents once, give agents only what they need"). The alternatives `docpluck` (taken on PyPI by a document-extraction project) and `extractkit` (several GitHub repos) were weaker.

## Decision

Use **docsluice**. On 2026-10-09 it was free on npm, on PyPI, as a GitHub user/org name, and no GitHub repository used it. A sluice is a gate that controls flow, which matches the core promise: content flows out, but only inside limits.

- npm package: `docsluice`
- npm scope for plugins: `@docsluice/*` (for example `@docsluice/ocr-tesseract`)
- Error base class: `DocsluiceError`. Document type: `DocsluiceDocument`.

## Consequences

- Check npm, the `@docsluice` scope and trademarks again before the first publish (issue: "Release: claim npm name and scope").
