# 7z (opt-in plugin)

`docsluice/7z` exports `sevenZipPlugin`, a format plugin that **lists** 7z archives ([ADR 0014](../adr/0014-7z-rar-listing-plugins.md)). The default registry does not include it:

```js
import { extract, createRegistry } from 'docsluice';
import { sevenZipPlugin } from 'docsluice/7z';

const registry = createRegistry();
registry.registerFormat(sevenZipPlugin);
const doc = await extract(bytes, { registry });
```

Without the plugin, a 7z file is detected as `7z` and fails with `UNSUPPORTED_FORMAT`.

## What is read

- The signature header, then the archive header. The header may be stored, or LZMA-encoded (7-Zip's default). The bounded LZMA decoder is written from the public-domain LZMA specification.
- File names, directories (empty streams without the empty-file flag, or the directory attribute), and sizes from the folders' unpack sizes and substream sizes.
- Every entry becomes a child in archive order: files `listed` with `sizeBytes`, directories `skipped`. Names are plain relative paths: `\` becomes `/`, and drive letters, `.`, `..` and control characters are removed.
- AES-encrypted contents set `features.isEncrypted`; their names are still listed. An AES-encrypted header fails with `ENCRYPTED`.
- The document has no blocks.

## Not read

- Entry contents: nothing is decompressed or extracted, so documents inside a 7z archive are not read.
- Times, attributes other than the directory flag, comments, and multi-volume sets.
- Headers coded with anything but Copy or LZMA (for example LZMA2 or a BCJ filter) fail with `CORRUPT_FILE`. 7-Zip writes LZMA headers.

## Safety

- Every NUMBER and count is checked against the bytes left before anything is allocated.
- A header larger than 64 MB is refused before it is decoded.
- The declared header size is also checked against `compressionRatio` (a hard limit, `LIMIT_EXCEEDED`) and `totalUncompressedBytes`. When the uncompressed allowance is spent, the listing is empty and truncated.
- The LZMA decoder writes into one buffer of the declared size. A match distance before the start, input that runs out, or a size that does not match fails with `CORRUPT_FILE`.
- Entries count against `zipEntries`; the listing stops at the limit with `TRUNCATED`.
- `children: 'skip'` adds no children.

## Corpus and generators

- `scripts/corpus/make-7z.mjs` writes `corpus/7z` with the 7-Zip command line. The archives cover:
  - the default LZMA header and a stored header;
  - encrypted contents and an encrypted header;
  - 300 similar names.
- `scripts/hostile/generate-listed-archives.mjs` writes `hostile/7z`:
  - a header that claims a 500,000:1 expansion;
  - an LZMA stream of garbage;
  - an overflowing NUMBER;
  - 12,000 entries.
