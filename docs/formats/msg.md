# Outlook MSG

The MSG reader opens the Microsoft compound file and reads the root message properties. It prefers the Unicode `001F` string stream when both Unicode and ANSI (`001E`) values exist. ANSI values use `PR_INTERNET_CPID` from `__properties_version1.0`; unsupported code pages fall back to Windows-1252 with an `ENCODING_GUESSED` warning.

The reader emits the subject, sender, recipients and submit time in a header table, uses the subject as the document title, and chooses the body in this order: `PR_BODY`, `PR_HTML`, then `PR_RTF_COMPRESSED`. HTML uses the shared HTML emitter. Compressed RTF follows the LZFu dictionary-reference and CRC rules in MS-OXRTFCP, checks the declared output size and compression ratio before allocation, charges each produced byte to the shared uncompressed-byte budget, and sends the resulting RTF through the RTF reader.

Binary attachment streams are passed to the shared child-document pipeline. Embedded-message storages (`PR_ATTACH_METHOD` = `ATTACH_EMBEDDED_MSG`) are rebuilt as bounded standalone CFB children and passed through the same pipeline; if reconstruction exceeds the active limits or encounters an unsupported layout, the reader reports `UNREADABLE_PART`. Recipients are read from recipient storages when root display fields are absent. Compressed RTF that contains `\fromhtml1` is de-encapsulated as HTML and sent through the shared HTML emitter.

The corpus sample `corpus/msg/test_outlook_msg.msg` is an unmodified Microsoft Outlook-produced fixture from MarkItDown's MIT-licensed test corpus; its source and license are recorded alongside the file. Property tags use a 32-bit value whose low 16 bits are the property type and high 16 bits are the property ID, as specified by Microsoft's [MS-OXMSG fixed-length property entry](https://learn.microsoft.com/en-us/openspecs/exchange_server_protocols/ms-oxmsg/3be0f1c8-6dec-46ea-ad81-1ad30b0ac816) and [MS-OXMSG glossary](https://learn.microsoft.com/en-us/openspecs/exchange_server_protocols/ms-oxmsg/fbe3a066-93b1-4726-98cb-55de21c823d6). The implementation also follows [MS-OXPROPS](https://learn.microsoft.com/en-us/openspecs/exchange_server_protocols/ms-oxprops/f6ab1613-aefe-447d-a49c-18217230b148), [MS-OXRTFCP](https://learn.microsoft.com/en-us/openspecs/exchange_server_protocols/ms-oxrtfcp/65dfe2df-1b69-43fc-8ebd-21819a7463fb), and [MS-OXRTFEX](https://learn.microsoft.com/en-us/openspecs/exchange_server_protocols/ms-oxrtfex/).
