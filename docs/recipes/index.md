# Recipes

Each recipe is a file in `examples/` with a test that runs against the built package, so the code on these pages works.

- [RAG ingestion](rag.md): chunks with heading context and citations for a vector index.
- [Handling uploads](upload.md): tight limits, a deadline, and an HTTP status for every error.
- [Redaction](redaction.md): mask e-mail addresses and ID numbers before anything is rendered.
- [OCR](ocr.md): hand embedded pictures and scanned pages to your OCR engine.
