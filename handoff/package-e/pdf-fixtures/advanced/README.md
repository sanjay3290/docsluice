# Advanced PDF source fixtures (preparation only)

These are original synthetic PDFs generated by `generate.py` with pypdf 6.10.0.
The generator is a preparation tool only; pypdf is not a proposed runtime or
repository dependency. It creates AES-256 encrypted PDFs with an empty user
password and a separate user password, a filled AcroForm (text and checkbox),
and sticky-note/free-text annotations. Fixture passwords are synthetic test
constants, not secrets.

`expected-source-facts.json` records the construction facts that the structural
tests assert. The tests use pypdf and, when installed, Poppler `pdftotext` to
check those facts independently. This is not acceptance by the future PDF
reader or engine. The frozen requirements archive remains unreadable, so these fixtures are not
presented as complete coverage of the requirements.

Encrypted output may contain randomized file identifiers; byte-for-byte
determinism is not claimed. Regeneration is constrained to pypdf 6.10.0, but
that constraint does not make the encrypted output bytes reproducible. Keep
generated PDFs and their `.license` sidecars together. The PDFs are original
synthetic materials released under CC0-1.0.

Run from this directory with:

```sh
python generate.py /tmp/advanced-pdf-fixtures
python test_fixtures.py
```
