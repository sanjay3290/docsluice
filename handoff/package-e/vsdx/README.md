# Synthetic VSDX fixture preparation for issue #88

These original, tiny packages exercise ZIP/OPC package structure and source-level Visio page/shape facts. They are generated by `generate_fixtures.py` using only Python's standard library. Every `.vsdx` has a neighboring `.license` file declaring the generated content CC0-1.0. No third-party images, Office documents, or Visio-authored files are included.

`tiny-flow.vsdx` contains a two-page drawing. Page order differs from ZIP member order and relationship order, so a reader must follow the page relationship IDs. Its source facts include Unicode and multiline text, grouped children, an empty shape, and connector records. `expected-source-facts.json` describes those bytes only; it is not parser output or an extraction golden. `member-hashes.json` records each package and member SHA-256 digest. Regeneration fixes ZIP timestamps, storage mode, permissions, and member order.

The other packages isolate malformed XML, an absent page relationship, duplicate shape IDs, a relationship target that traverses outside the package root, and a DTD/external-entity candidate. The hostile XML case is inspected only as raw bytes by the tests and must not be sent to an unsafe XML parser. These are bounded adversarial samples, not real-world corpus samples.

Run the independent structural checks with:

```sh
python -m unittest -v test_fixtures.py
python generate_fixtures.py
```

The fixtures are not validated by opening or rendering them in Microsoft Visio. In particular, they are structural test packages and should not be described as Visio-application-validated drawings.

## Primary format references

- Microsoft, [Introduction to the Visio file format (.vsdx)](https://learn.microsoft.com/en-us/office/client-developer/visio/introduction-to-the-visio-file-formatvsdx): VSDX is an OPC/XML package whose structure is defined through package parts and relationships.
- Microsoft Open Specifications, [MS-VSDX Document XML Part](https://learn.microsoft.com/en-us/openspecs/sharepoint_protocols/ms-vsdx/7ec3d7b0-0de2-4711-a7b6-92daa2020d71): document part root, content type, and relationship to Pages.
- Microsoft Open Specifications, [MS-VSDX Pages XML Part](https://learn.microsoft.com/en-us/openspecs/sharepoint_protocols/ms-vsdx/947b485d-676a-480b-96e6-c0e4d1bf58f3) and [Pages XML sample](https://learn.microsoft.com/en-us/openspecs/sharepoint_protocols/ms-vsdx/6b73fe7e-68a4-4f26-846a-891950e0329e): page list entries and their relationship references.
- Microsoft Open Specifications, [MS-VSDX Page XML Part](https://learn.microsoft.com/en-us/openspecs/sharepoint_protocols/ms-vsdx/1f15c8f0-6565-465c-aefd-2be6af545e8a) and [Page XML sample](https://learn.microsoft.com/en-us/openspecs/sharepoint_protocols/ms-vsdx/dccbb4b5-ca0c-43ef-9379-00c1acb54377): page content and shape/text/connect records.
- Microsoft Open Specifications, [ShapeSheet_Type](https://learn.microsoft.com/en-us/openspecs/sharepoint_protocols/ms-vsdx/5d6be8d6-1cab-4722-ba32-d73febc4e51d) and [Page_Type](https://learn.microsoft.com/en-us/openspecs/sharepoint_protocols/ms-vsdx/27e583c3-0ef3-4d7c-8fac-e37bd18d9dc2): relevant shape/page identifiers and element definitions.
